# /watch-video — посмотреть видео

```bash
python3 tools/watch.py <ссылка|файл>                       # весь ролик: кадры + речь
python3 tools/watch.py <ссылка|файл> --start 0 --end 4     # кусок плотнее (хук — первые 3–4 с)
python3 tools/watch.py <файл> --at 1.5,7.2                 # + кадры в конкретные моменты
python3 tools/watch.py <файл> --width 1024                 # крупнее — читать мелкий текст на экране
python3 tools/watch.py <файл> --no-speech                  # без расшифровки (быстрее)
```

## Как смотреть
1. Запусти скрипт. Он печатает отчёт (`videos/_watch/<имя>/report.md`): длительность, число склеек и средний шот,
   список кадров с таймкодами, речь по фразам.
2. **Открой кадры** — все из списка, одним сообщением (параллельно). Для обзора хватит `sheet.jpg` (контакт-лист),
   для деталей (шрифт, цвета субтитров, мелкие плашки) — отдельные кадры.
3. Сопоставь кадры и речь по таймкодам и ответь на вопрос. Без вопроса — коротко: структура, хук (что на экране
   в первые 2 с), как сделаны субтитры, какая графика и где, темп, финал.
4. Нужна деталь — повтори на куске: `--start/--end` (плотнее) или `--at` в моменты, где говорят «смотри», «вот здесь».
   Повторно уже просмотренное видео не гоняй — кадры у тебя есть.

## Что смотреть в референсе монтажа
- **Хук:** что на экране с кадра 0, есть ли заголовок, движение, лицо.
- **Субтитры:** где (низ / центр / стык), сколько слов, капс, плашка / обводка / подсветка слова, цвета, шрифт.
- **Раскладки:** графика сверху + лицо снизу, графика на весь экран, только лицо; как часто меняются.
- **Темп:** средний шот (из отчёта), наезды, jump-cut.
- **Графика:** что показывают (скрины, списки, цифры, логотипы, видеовставки), в каких цветах; есть ли она вообще.
- **Движение:** как появляются надписи и карточки — выпрыгивают с отскоком, плавно, резко, медленно. По одному кадру
  не видно: посмотри 1 с плотно (`--start S --end S+1 --frames 12`).
- **Карточки:** с тенью, плоские, с рамкой, полупрозрачные «стеклянные».
- **Приближения:** наезжает ли кадр на лицо на склейках и акцентах.
- **Звук:** есть ли музыка/эффекты — по кадрам не видно; спроси или послушай расшифровку пауз.
- **Финал:** CTA, плашка, кодовое слово.

## Ограничения
- Закрытые, удалённые, приватные ролики и некоторые Instagram без входа не скачиваются — попроси файл
  (в Instagram: «Сохранить» → переслать себе или скачать через любой сервис и положить в `inbox/`).
- Звук целиком агент не слышит — только расшифровку речи. Музыку и эффекты оценивай со слов клиента.
- После разбора можно удалить `videos/_watch/<имя>/`, если видео больше не понадобится.
