# /setup-studio — настройка монтажа за 8 вопросов

Цель — как можно быстрее показать клиенту его ролик в его стиле. Спрашиваем **только то, что меняет монтаж**,
и не спрашиваем то, что видно из присланных файлов. Анкета — `docs/QUESTIONS.md`.

## 0. Старт
1. Есть `studio/onboarding.md` → продолжение: коротко скажи, что уже есть и чего ждём, продолжи с «Текущий вопрос».
   Иначе скопируй `docs/onboarding-template.md` → `studio/onboarding.md`.
2. `./setup.sh --check` — молча. Не хватает обязательного (Node.js 22+, Python, ffmpeg…) → скажи клиенту простыми
   словами, чего не хватает и зачем, и запусти `./setup.sh` (Node.js и Python он не ставит — дай ссылку nodejs.org /
   команду из README). Пока ставится — продолжай анкету. **HeyGen на старте не подключай** — он нужен только для
   музыки из каталога, предложишь на вопросе 6.
3. **Первое сообщение клиенту** — коротко:
   - одна строка: «Настроим монтаж под тебя: 8 коротких вопросов, потом покажу, как будут выглядеть твои ролики»;
   - **список из 8 вопросов** — раздел «Коротко» из `docs/QUESTIONS.md`;
   - «Главное — 3–5 роликов, монтаж которых тебе нравится: ссылки или файлы в `inbox/`, я их сам посмотрю»;
   - **вопрос 1.**

## 1. Цикл: один вопрос → ответ → запись
1. Задай **один** вопрос. Где есть выбор (субтитры, темп, музыка) — дай варианты, лучше картинкой
   (`docs/presets.jpg` или превью), а не открытый вопрос.
2. Получив ответ:
   - запиши в `studio/onboarding.md` (✅, коротко словами клиента, путь к материалу);
   - сделай обработку из «Подробно» (`docs/QUESTIONS.md`): `studio.py set …`, разбор видео/референсов, логотип, шрифт;
     обнови `studio/profile.md` (шаблон `docs/profile-template.md`);
   - одной фразой подтверди («Записал: живая съёмка, горизонтально — кадрирую по центру»), задай следующий.
3. **Уже понятно из файлов или прошлых ответов** — не спрашивай, отметь ✅. Референсы обычно сразу отвечают на
   субтитры и темп: тогда задай эти вопросы как подтверждение («Субтитры как у референса — белые капсом с жёлтой
   плашкой на слове. Оставляем?»).
4. **«Не знаю» / «пропусти»** → вариант по умолчанию из «Если нет», ⏭, дальше.
5. **Нет материала** → одной фразой: зачем он и что будет без него, **порекомендуй прислать**, ⏳, дальше.
   Настойчиво — только референсы (2). Своё видео (1) — по желанию: можно ответить словами.
6. Прислал материал не к текущему вопросу — обработай, отметь в нужной строке, вернись к текущему.

## 2. После вопроса 8
1. Есть ⏳ → одним списком: чего не хватает и что это даст; предложи прислать сейчас. Нет — едем с умолчаниями.
2. Нет `studio/studio.json` → `python3 tools/studio.py init <ближайший пресет>` и применить ответы через `studio.py set`;
   `python3 tools/studio.py fonts`. Пресет — только цвета и шрифты для старта; **как монтировать** берётся из
   референсов и ответов клиента. Проверь, что записаны `montage.hook`, `montage.pace`, `motion.feel`,
   `surface.kind`, `montage.punches`, `source.jumpcuts`; что осталось по умолчанию — назови клиенту простыми словами
   («надписи будут появляться плавно — так по умолчанию, можно с отскоком»).
3. `python3 tools/style_preview.py` (на `studio/sample.mp4`, если клиент прислал своё видео; иначе на заглушке) →
   **покажи `studio/preview.jpg`** и рядом 1–2 кадра референса — чтобы клиент сравнил.
   Правки → `studio.py set` → превью снова, пока клиент не скажет «да». Как двигаются надписи, по картинке не
   видно — покажи 15-секундный ролик `--render` (`videos/_style-preview/output.mp4`).
   Голова режется / текст на лице → `source.split_pos`, `source.face_top` (`docs/STYLE.md`).
4. `python3 tools/studio.py check` → ✓; отметь чек-лист в `studio/onboarding.md`.
5. Итог в 3–5 строк + превью + что дальше: «кидай видео в `inbox/` и пиши „смонтируй ролик“ (/make-reel)».

## Правила общения
- Клиент может быть не техническим и ничего не знать о монтаже: никаких «JSON», «CSS», «hex», «сплит», «хук»,
  «джамп-кат» — описывай, что видно на экране (словарик — `AGENTS.md`). Команды запускаешь сам.
- Один вопрос за раз. Попросил «давай всё сразу» — принимай ответы списком.
