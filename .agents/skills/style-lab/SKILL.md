# /style-lab — примерка стиля

Справочник полей — `docs/STYLE.md`. Текущее: `python3 tools/studio.py show`.

## Цикл
1. Пойми, что клиент хочет поменять. Расплывчатое («поярче», «дороже», «как у блогеров») переведи в 2–3
   конкретных варианта и спроси, какой ближе:
   - «дороже» → тёмная графика, тонкий шрифт заголовков, без капса, приглушённый акцент, `motion.feel=calm`,
     `surface.kind=flat` или `outline`;
   - «поярче/динамичнее/поживее» → насыщенный акцент, `captions.style=highlight` или `word`, капс,
     `montage.pace=dynamic`, `motion.feel=bouncy` или `snappy`;
   - «спокойнее» → `outline`, без капса, `max_words` 4–5, `pace=minimal`, `motion.feel=calm`;
   - «без всего, только я и субтитры» → `montage.pace=none`, `montage.hook=false`;
   - «надписи прыгают / слишком резко / слишком медленно» → `motion.feel` (`smooth` · `bouncy` · `snappy` · `calm`)
     и `motion.speed` (1.2 — быстрее, 0.8 — медленнее);
   - «без теней / с рамкой / как стекло» → `surface.kind=flat` · `outline` · `glass`.
   Варианты предлагай словами, а не названиями настроек: «плавно выезжают», «выпрыгивают с отскоком».
2. Внеси правку: `python3 tools/studio.py set ключ=значение …` (шрифт — `python3 tools/fonts.py add "Name"`).
   Хочет вернуть прежний вариант — сначала сохрани копию: `cp studio/studio.json studio/studio.prev.json`.
3. `python3 tools/style_preview.py` → покажи `studio/preview.jpg` (кадры: начало · список · число · приближение ·
   титул · призыв). Правка движения (`motion`) — покажи ролик: `--render`.
4. `python3 tools/studio.py check` — контраст и шрифты.
5. Повторяй, пока клиент не подтвердит. Итог запиши одной строкой в `studio/profile.md` → «Визуальный стиль».

## Стиль с референса
Ссылка или файл → посмотри: `python3 tools/watch.py <ссылка|файл>` (`.agents/skills/watch-video/SKILL.md`), затем
`python3 tools/ref_analyze.py <видео> studio/references/<имя>` → смотри `ref/frames/*.jpg`, палитру в
`ref/style.json`. Опиши, что видишь (субтитры: где, размер, капс, плашка/обводка, цвет активного слова;
шрифт заголовков; плашки и карточки; как появляются надписи — плотно, `watch.py --start S --end S+1 --frames 12`;
темп), предложи соответствие в studio.json, примени, покажи превью рядом с кадром
референса. Шрифт референса угадай по форме (гротеск/антиква/геометрия/рукописный) и предложи 2–3 похожих из
Google Fonts с кириллицей.

## Положение спикера
Голова режется в split → `source.split_pos` (`"50% 30%"` — выше). Заголовок хука ложится на лицо →
`source.face_top` (меньше число = голова выше). Горизонтальное видео не по центру → `source.crop_x`.
Проверяй на превью с пробником клиента (`studio/sample.mp4`).
