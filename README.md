# Video Editor AI — ИИ-монтажёр вертикальных роликов в твоём стиле

Агент для **Claude Code** и **Codex**, который монтирует Reels, Shorts и TikTok из видео, где ты говоришь в камеру
(или из ИИ-аватара). Один раз отвечаешь на 8 вопросов о стиле монтажа и присылаешь ролики, которые нравятся. Дальше
кидаешь новое видео в папку и пишешь «смонтируй ролик» — получаешь готовый MP4 1080×1920 в своём стиле.

![Примеры стилей: Неон, Тёплый лайфстайл, Деловой, Слово за словом](docs/presets.jpg)

**Что агент делает с видео:**
- **чистит живую запись** — паузы, «э-э», неудачные дубли, повторы слов;
- **ставит субтитры** в твоём стиле — плашка, подсветка слова, обводка или по одному слову;
- **делает хук** с первого кадра — заголовок, который не даёт пролистать;
- **подбирает графику** под фразы — списки, цифры, сравнения, титулы, скрины сайтов, логотипы, b-roll, чат с ИИ;
- **держит ритм** — наезды на лицо, смена раскладок, jump-cut на склейках;
- **сводит звук** — эффекты, фоновая музыка под темп, громкость под соцсети;
- **смотрит видео** — твои референсы по ссылке (YouTube, Reels, TikTok) и свой готовый ролик перед сдачей;
- **заканчивает призывом** — «напиши СЛОВО в комментарии» — и рендерит MP4.

Подходит для **живой съёмки** с телефона или камеры (вертикально или горизонтально) и для **ИИ-аватаров** (HeyGen и др.).

## Как это работает

```
 твоё видео ──► чистка ──► распознавание ──► агент-режиссёр ──► сборка ──► проверка ──► MP4
               паузы,      слова с          выбирает сцены     в твоём    агент сам
               дубли       таймкодами       под каждую фразу   стиле      смотрит ролик
```

1. **Настройка (один раз).** Агент задаёт 8 вопросов о монтаже, смотрит твои ролики-референсы, подбирает цвета,
   шрифты, субтитры и темп и показывает превью. Всё это сохраняется в папке `studio/` — это «память» о твоём стиле.
2. **Монтаж (каждый ролик).** Агент чистит запись, распознаёт речь, раскладывает фразы на сцены из библиотеки
   (≈20 типов), собирает ролик на движке [HyperFrames](https://hyperframes.dev), сам просматривает результат,
   исправляет и рендерит MP4.
3. **Правки словами.** «Субтитры крупнее», «меньше графики», «сделай поярче» — агент меняет и запоминает,
   если правка касается всех роликов.

Графику агент не рисует руками. Он выбирает готовые сцены и заполняет их данными, поэтому ролики выглядят
единообразно и предсказуемо.

| | |

## Установка

### 1. Node.js и Python
- **Node.js 22 или новее:** скачай LTS-установщик с [nodejs.org](https://nodejs.org) и установи как обычную программу.
- **Python 3:** на Mac открой Терминал и набери `python3` — если его нет, macOS сама предложит установить
  «инструменты разработчика», соглашайся. На Linux он обычно уже есть.

### 2. Скачай проект
Через терминал:

```bash
git clone https://github.com/neprostomaksim/Video_editor_ai.git
cd Video_editor_ai
```

Или без git: на странице репозитория нажми **Code → Download ZIP**, распакуй и открой папку в терминале
(на Mac: правой кнопкой по папке → «Новый терминал по адресу папки»).

### 3. Запусти установку

```bash
./setup.sh
```

Скрипт кладёт всё нужное прямо в папку проекта — без Homebrew и прав администратора: ffmpeg, yt-dlp (видео по
ссылкам), модель распознавания речи (~470 МБ, один раз), браузер для рендера, официальные скиллы HyperFrames.
Проверить, всё ли на месте: `./setup.sh --check`. Аккаунты и ключи для монтажа не нужны.

### 4. Поставь агента — Claude Code или Codex

**Claude Code**

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Потом в папке проекта запусти `claude` и войди в аккаунт Claude через браузер. Нужна версия 2.1.277 или новее
(`claude --version`, обновить — `claude update`). Можно и без терминала: приложение Claude для
[macOS и Windows](https://claude.com/download) → вкладка **Code** → открыть папку проекта.
Подробнее — [документация Claude Code](https://code.claude.com/docs/en/setup).

**Codex**

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

или `npm install -g @openai/codex`. Потом в папке проекта запусти `codex` и выбери **Sign in with ChatGPT**.
Есть также приложение и расширение для редакторов. Подробнее — [документация Codex](https://developers.openai.com/codex/cli).

### Windows
Установи WSL: открой PowerShell и выполни `wsl --install`, перезагрузись. Дальше открой **Ubuntu** из меню «Пуск»
и делай все шаги выше внутри неё. Node.js 22 и Python там ставятся так:

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs python3 git
```

## Первый запуск: настройка стиля

Открой агента **в папке проекта** и напиши что угодно, например «привет». Агент увидит, что монтаж ещё не настроен,
покажет список вопросов и задаст их по одному:

1. Как ты снимаешь: ИИ-аватар или сам на камеру, вертикально или горизонтально?
2. Пришли 3–5 роликов, монтаж которых тебе нравится, и скажи, что в них нравится.
3. Есть фирменные цвета, шрифт или логотип?
4. Какие субтитры? (покажет 4 варианта)
5. Какой темп монтажа: спокойный, стандартный или динамичный?
6. Музыка и звуковые эффекты: нужны? Какое настроение?
7. Что в конце ролика? («напиши слово ГАЙД в комментарии», «подпишись», ничего)
8. О чём ролики и какие названия часто звучат?

Отвечать можно коротко, «не знаю» или «пропусти» — агент предложит вариант сам. Прервался — в следующий раз
продолжит с того же места. В конце покажет **превью твоего стиля** и поправит, пока не скажешь «да, это моё».

**Что подготовить заранее:**
- ⭐ **3–5 роликов-референсов** — ссылки или файлы. Это главное: по ним агент поймёт твой стиль;
- по желанию — своё видео, как обычно снимаешь (превью будет на твоём кадре);
- если есть — логотип (PNG), фирменные цвета и шрифт, свои треки с лицензией.

Файлы кидай в папку `inbox/`, ссылки — прямо в чат.

## Монтаж ролика

1. Положи видео в `inbox/` (можно добавить сценарий, картинки, записи экрана).
2. Напиши агенту: **«смонтируй ролик»**. Можно уточнить: «вот референс, сделай похоже», «кодовое слово — ГАЙД».
3. Агент покажет раскадровку («время — что на экране») и соберёт ролик. Готовое видео — в
   `videos/<название>/output.mp4` (лёгкая копия для телефона — `output_web.mp4`).
4. Правки — словами: «первую сцену короче», «субтитры крупнее», «убери музыку».

**Команды.** В Claude Code — слэш-команды, в Codex и вообще везде — обычными словами:

| Что нужно | Claude Code | Словами |
|---|---|---|
| Настроить стиль (заново) | `/setup-studio` | «настрой монтаж под меня» |
| Смонтировать ролик | `/make-reel` | «смонтируй ролик» |
| Поменять стиль | `/style-lab` | «поменяй субтитры / цвета / шрифт» |
| Посмотреть видео | `/watch-video` | «посмотри этот ролик: <ссылка>» |

## Что внутри

```
AGENTS.md         главная инструкция для агента (её читают и Claude Code, и Codex)
.agents/skills/   сценарии: setup-studio, make-reel, style-lab, watch-video
studio/           твой стиль: профиль, настройки, референсы, логотипы, шрифты, музыка   ← заполняет агент
inbox/            сюда кидаешь видео и материалы
videos/           проекты роликов и готовые MP4
engine/           движок: сборщик и библиотека сцен
tools/            инструменты: просмотр видео, распознавание, чистка, захват сайтов, музыка, стиль
presets/          готовые стили: Чистый, Лайм-тех, Неон, Деловой, Тёплый лайфстайл, Слово за словом
docs/             анкета, правила режиссёра, монтаж по референсу, справочник стиля
```

Твои видео, стиль и материалы (`inbox/`, `videos/`, `studio/`) не попадают в git — они остаются только у тебя.
Справочник всех настроек стиля — [docs/STYLE.md](docs/STYLE.md), правила монтажа — [docs/DIRECTOR.md](docs/DIRECTOR.md).

## Вопросы и проблемы

**Агент не начинает настройку.** Запускай агента именно в папке проекта. В Claude Code обнови версию (`claude update`):
чтение `AGENTS.md` появилось в 2.1.277. Если выше по папкам лежит чей-то `CLAUDE.md`, Claude читает его вместо
`AGENTS.md` — просто напиши: «прочитай AGENTS.md и начни настройку».

**Не скачивается ролик по ссылке.** Закрытые, удалённые ролики и часть Instagram без входа не скачиваются —
сохрани видео и положи файл в `inbox/`.

**Первое распознавание речи долгое.** При первом запуске скачивается модель (~470 МБ) — это один раз.

**Нужна ли регистрация в HeyGen?** Для монтажа — нет: распознавание, сборка и рендер работают без аккаунтов.
HeyGen нужен только для **музыки из их каталога** (10 000+ треков) — агент предложит подключить на вопросе о музыке,
или сам: `./setup.sh --heygen` (вход через браузер, бесплатный аккаунт подходит). Без него — свои треки в
`studio/music/` (агент подберёт по темпу) или ролик без музыки.

**Ролик рендерится долго.** Рендер минутного ролика — 1–3 минуты в зависимости от компьютера.

## Ручной режим (без агента)

```bash
python3 tools/studio.py presets                       # готовые стили
python3 tools/studio.py init neon                     # выбрать стиль
python3 tools/style_preview.py                        # превью → studio/preview.jpg
python3 tools/watch.py <ссылка|файл>                  # посмотреть видео: кадры + речь
python3 tools/cleanup.py raw.mp4 videos/my-reel       # план чистки живой записи → videos/my-reel/source/plan.md
python3 tools/cleanup.py raw.mp4 videos/my-reel --apply
python3 tools/transcribe.py videos/my-reel/source/clean.mp4 videos/my-reel
# написать videos/my-reel/shotlist.json по docs/DIRECTOR.md (каталог сцен: python3 engine/catalog.py)
python3 engine/build.py videos/my-reel
./hf render videos/my-reel/public -o videos/my-reel/output.mp4 --fps 25
python3 tools/finalize.py videos/my-reel
```

## Права
- Движок видео — [HyperFrames](https://hyperframes.dev) (HeyGen).
- Звуковые эффекты — Pixabay (коммерческое использование разрешено, см. `assets/sfx/CREDITS.md`).
- Шрифты — Google Fonts / Fontsource (OFL).
- Логотипы сервисов — товарные знаки их владельцев; используются для упоминания сервиса в ролике.
- Музыка — свои треки с лицензией (`studio/music/`) или каталог HeyGen.
- Ролики-референсы — только как ориентир по стилю. Чужое лицо, голос и субтитры в свои ролики не переносим.
