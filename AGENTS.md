# AI Montage Kit — инструкция для агента

Это студия монтажа вертикальных роликов (Reels / TikTok / Shorts) на движке HyperFrames. Пользователь — автор
контента, часто не программист. Он присылает видео спикера (ИИ-аватар или живая запись), а ты монтируешь
ролик **в его стиле**: чистка, субтитры, хук, графика, звук, CTA.

## Маршрутизация
| Ситуация | Что делать |
|---|---|
| Нет `studio/studio.json` или `studio/profile.md` | Студия не настроена → **настройка**: `.claude/skills/setup-studio/SKILL.md`. Предложи начать с неё, даже если просят сразу смонтировать |
| Прислали видео спикера / «смонтируй», «сделай ролик» / новый файл в `inbox/` | **Монтаж**: `.claude/skills/make-reel/SKILL.md` |
| «Поменяй цвет / шрифт / субтитры», «как будет выглядеть» | **Стиль**: `.claude/skills/style-lab/SKILL.md` |
| Прислали статистику ролика | Допиши выводы в `studio/profile.md` → «Что сработало / провалилось» |

В Claude Code это слэш-команды `/setup-studio`, `/make-reel`, `/style-lab`. В других агентах (Codex, Cursor…)
прочитай соответствующий SKILL.md и следуй ему.

## Карта проекта
```
studio/          ПРОФИЛЬ КЛИЕНТА — всё, что делает ролики «его»
  profile.md       кто, для кого, тон, CTA, запреты, что сработало   (пишет /setup-studio)
  studio.json      стиль и правила монтажа — только отличия от engine/defaults.json (docs/STYLE.md)
  references/      разобранные референсы стиля · logos/ fonts/ music/ — свои логотипы, шрифты, треки
  glossary.json    исправления распознавания речи · sample.mp4 — пробное видео спикера · preview.jpg — превью стиля
inbox/           сюда клиент кидает видео, сценарии, референсы
videos/<slug>/   проекты роликов: words.json, transcript.txt, shotlist.json, public/, output.mp4
engine/          сборщик (build.py), ядро (core.py), библиотека сцен (scenes/*.py), defaults.json
tools/           transcribe, cleanup, ref_analyze, clip, captures, logos, fonts, music, studio, style_preview, finalize
presets/         готовые стили · docs/ правила режиссёра, режим референса, справочник стиля, шаблон профиля
assets/          встроенные шрифты, звуки, логотипы, базовый глоссарий
```

## Правила
- **Стиль — только из студии.** Не хардкодь цвета/шрифты в сценах и раскадровке; разовое отличие — блоки
  `theme`/`captions`/`cta_style` в shotlist.json. В CSS сцен — токены `var(--accent)`, `var(--ink)`… и шрифты `'Head'`, `'Body'`, `'Mono'`.
- **Факты не выдумываем**: цифры, цены, названия, цитаты — из речи, проверенных источников или от клиента.
- **Сам смотри на результат** (снапшоты, превью) до того, как показать клиенту.
- **Не трогай** `engine/defaults.json` и `assets/` ради одного клиента — для этого `studio/`.
- С клиентом — простым языком, без «JSON», «CSS», «LUFS». Команды запускаешь ты.
- Новый приём, который пригодится снова → новая сцена в `engine/scenes/` + строка в `docs/DIRECTOR.md §2`.
