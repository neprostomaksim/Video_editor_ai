# studio — профиль клиента

Всё, что делает ролики «твоими». Заполняется командой `/setup-studio`, правится `/style-lab`.

| файл | что это |
|---|---|
| `onboarding.md` | анкета настройки: ответы и что ещё ждём (агент продолжает с того же места) |
| `profile.md` | тема роликов, источник видео, стиль, звук, финал, правки клиента |
| `studio.json` | визуальный стиль и правила монтажа (справочник — `docs/STYLE.md`) |
| `sample.mp4` | пробное видео спикера — на нём строится превью |
| `preview.jpg` | превью стиля: хук · список · число · удар · титул · CTA |
| `references/` | разобранные ролики-референсы |
| `logos/` | свои логотипы (PNG) → `python3 tools/logos.py sync` |
| `fonts/` | шрифты (`python3 tools/fonts.py add "Название"`) |
| `music/` | свои треки с лицензией — музыка берётся отсюда в первую очередь |
| `glossary.json` | исправления распознавания: как правильно пишутся названия из твоих роликов |
