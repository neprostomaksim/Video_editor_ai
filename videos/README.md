# videos — проекты роликов

`videos/<slug>/` — один ролик: `source/` (чистка живой записи), `words.json` + `transcript.txt` (речь с таймкодами),
`shotlist.json` (раскадровка), `captures/` и `media/` (материалы), `public/` (сборка), `output.mp4` (готовый ролик).
Служебные: `_sample` — пробник спикера, `_style-preview` — превью стиля.
