# inbox — входящие

Кидай сюда всё для нового ролика и пиши агенту `/make-reel`:
- видео спикера (ИИ-аватар или запись с телефона/камеры) — `.mp4` / `.mov`;
- сценарий (`.txt` / `.md`), если есть — по нему агент проверит названия и кодовое слово;
- ролик-референс, если хочешь смонтировать «как этот»;
- картинки, записи экрана, логотипы, которые нужно показать.

Имена файлов любые. После монтажа материалы переезжают в `videos/<ролик>/`.
